# resolution rust projects

projects i made for resolution rust. i got to learn more rust and made a couple interesting projects.

## rubsidian
markdown-style editor inspired by obsidian but written in rust. it features a live preview and allows you to edit markdown side by side with it.

## gh-cli
cli allowing you to search through github repos from the command line. it sorts by stars and allows you to see stuff like total stars and repo description.

### contributing
to run this locally, you will need to have rust and cargo installed. `rubsidian` will need the specified `eframe` version while `gh_cli` will need `reqwest` and `serde`.
then just make a pr with your changes :D
